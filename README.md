## 📌 About the Project

**FoodCycle AI** is an Android-based prototype designed to help reduce food waste through intelligent food demand prediction, surplus food management, quality monitoring, and sustainable food redistribution.

The project aims to connect institutional kitchens, food processing units, and food redistribution organizations through a smart digital ecosystem.

By combining technology with sustainable practices, FoodCycle AI aims to minimize food waste, improve resource utilization, and make surplus food available to people who need it.

## 🎯 Project Objectives

- Reduce food waste in institutional kitchens and food processing units.
- Predict food demand and identify potential surplus.
- Monitor food quality and freshness.
- Connect surplus food providers with NGOs and redistribution organizations.
- Improve food collection and delivery planning.
- Promote sustainability through data-driven decision-making.

## ✨ Key Modules

The Android prototype includes dedicated screens and modules for:

| Module | Purpose |
|---|---|

## 🚀 Getting Started

Follow these steps to run the project locally.

### Prerequisites
- Android Studio
- Android SDK
- JDK compatible with your Android Gradle project
- Android device or emulator

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/Yuvi288/FoodCycle-AI.git
   ```

2. Open Android Studio.

3. Select **Open** and choose the downloaded `FoodCycleAI` project folder.

4. Allow Gradle to sync.

5. Connect an Android device or start an emulator.

6. Click **Run ▶** to launch the application.
